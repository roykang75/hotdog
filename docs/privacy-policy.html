Section 1 — Data Collection

수집하는 데이터

Hotdog Translator는 사용자의 개인 정보를 수집하거나 외부 서버로 전송하지 않습니다. 모든 데이터는 사용자의 기기에만 저장됩니다.

이 확장 프로그램은 다음 데이터를 수집하지 않습니다.

  • 이름, 이메일 주소, 연락처 등 개인 식별 정보
  • 사용자의 브라우징 기록 또는 방문 URL
  • 사용자 계정 정보 또는 로그인 자격 증명
  • 기기 정보, 위치 데이터 또는 IP 주소
  • 번역된 텍스트 콘텐츠 (외부 전송 없음)

번역 기능을 위해 처리되는 텍스트는 번역 요청 시에만 선택된 번역 서비스(Google Translate API 또는 사용자가 직접 설정한 AI 서버)로 전송되며, 그 외에는 어디에도 전송되지 않습니다.

Section 2 — Permissions

권한 사용 목적

이 확장 프로그램이 요청하는 각 권한의 사용 목적은 다음과 같습니다.

권한 사용 목적
<all_urls> 모든 웹 페이지에서 플로팅 번역 버튼(FAB)을 표시하고, 사용자가 선택한 텍스트 또는 페이지 콘텐츠를 번역하기 위해 필요합니다. 이 권한으로 페이지를 추적하거나 데이터를 수집하지 않습니다.
activeTab 현재 활성화된 탭에서만 번역 작업을 수행하기 위해 사용됩니다. 백그라운드에서 탭을 감시하지 않습니다.
storage 번역 캐시, 사용자 설정(번역 언어, API 설정 등)을 기기 로컬에 저장합니다. 외부 서버와 동기화되지 않습니다.
scripting 웹 페이지에 번역 UI(플로팅 버튼, 번역 결과 오버레이)를 삽입하기 위해 사용됩니다.
Section 3 — Network Requests

네트워크 요청

이 확장 프로그램이 외부로 통신하는 경우는 다음 세 가지뿐입니다.

  1. Google Translate API (무료, 인증 불필요)
    기본 번역 서비스로 사용됩니다. 번역할 텍스트가 Google 서버로 전송되며, Google의 개인정보 처리방침이 적용됩니다. 사용자 인증 정보나 API 키는 전송되지 않습니다.
  2. 사용자 설정 AI 서버 (선택 사항)
    사용자가 직접 설정한 경우에 한해 OpenAI API 또는 GitHub Models 엔드포인트로 번역 요청이 전송됩니다. API 키는 사용자가 직접 입력하며, 기기 로컬에만 저장됩니다. 이 기능은 사용자가 명시적으로 설정한 경우에만 활성화됩니다.
  3. YouTube 자막 데이터 캡처
    YouTube 페이지에서 자막 번역을 위해 YouTube의 자막 네트워크 요청(fetch/XHR)을 가로채어 자막 텍스트를 추출합니다. 이는 자막 번역만을 목적으로 하며, 사용자 활동을 추적하거나 기록하지 않습니다. 캡처한 자막 데이터는 번역 후 즉시 처리되며 외부로 전송되지 않습니다.

위의 번역 서비스 외에, 이 확장 프로그램은 어떤 서버와도 통신하지 않습니다. 사용 통계, 오류 보고, 분석 데이터를 수집하는 원격 측정(telemetry) 기능이 없습니다.

Section 4 — Data Storage

데이터 저장

이 확장 프로그램은 chrome.storage.local을 사용하여 다음 데이터를 사용자 기기에만 저장합니다.

  • 번역 캐시: 동일한 텍스트의 반복 번역 속도를 높이기 위해 이전 번역 결과를 로컬에 캐시합니다. 캐시는 외부로 전송되지 않으며 사용자가 언제든지 삭제할 수 있습니다.
  • 사용자 설정: 번역 대상 언어, 선택한 번역 서비스, AI API 엔드포인트 설정 등 사용자 환경 설정이 로컬에 저장됩니다.
  • API 키 (선택 사항): 사용자가 AI 서비스를 설정한 경우, 입력한 API 키가 기기 로컬에 저장됩니다. 이 키는 해당 AI 서비스 요청 외 다른 목적으로 사용되지 않습니다.

저장된 모든 데이터는 Chrome 브라우저의 로컬 저장소에 보관되며, Chrome 동기화(sync)를 사용하지 않습니다. 확장 프로그램을 삭제하면 모든 저장 데이터가 함께 삭제됩니다.

Section 5 — Third-Party Services

제3자 서비스

이 확장 프로그램과 연동될 수 있는 제3자 서비스 및 해당 개인정보 처리방침은 다음과 같습니다.

  • Google Translate — Google 개인정보 처리방침
  • OpenAI (사용자 설정 시) — OpenAI 개인정보 처리방침
  • GitHub Models (사용자 설정 시) — GitHub 개인정보 처리방침

각 제3자 서비스의 개인정보 처리 방식은 해당 서비스의 정책을 따르며, Hotdog Translator는 이에 대해 책임지지 않습니다. AI 서비스 사용은 전적으로 선택 사항이며, 사용자가 직접 설정하지 않는 한 활성화되지 않습니다.
